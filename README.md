# Java Practice

Java programs I solved myself while learning, organized by topic. I'm building these skills to move into **test automation** (Selenium, TestNG, REST Assured), so the later folders focus on Java used in testing.

## Topics

| Folder | What's inside |
|--------|---------------|
| `01-basics` | Prime check, Fibonacci, swapping numbers, loops |
| `02-strings` | Palindrome, reverse string, vowel count |
| `03-arrays` | Largest element, remove duplicates, sorting |
| `04-oop` | Inheritance, polymorphism, abstraction, encapsulation |
| `05-collections` | ArrayList, HashMap, HashSet examples |
| `06-exception-handling` | try/catch/finally, custom exceptions |
| `07-file-handling` | Reading and writing files |
| `08-qa-focused` | Reading Excel and properties files, string utilities for testing |

## How to run

1. Install JDK 17 or later.
2. Clone the repo:
```
   git clone https://github.com/uttamnarzary/java-practice.git
   cd java-practice
```
3. Compile and run any file, for example:
```
   cd 02-strings
   javac PalindromeCheck.java
   java PalindromeCheck
```
